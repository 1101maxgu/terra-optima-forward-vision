# GeoViva hardware concept images: ChatGPT prompts

The hardware is a **proposed concept, not built or tested**. These images exist only to help judges picture it.
Every image must be labelled on slides: **"AI-generated concept image — not a photo of built hardware."**

## How to use

1. Open a new ChatGPT chat with image generation.
2. Paste the **shared style block** first, then prompt 1. Generate prompts 2 and 3 in the same chat so the enclosure stays consistent.
3. For each image, ask for the 16:9 version first, then the square variant ("Now make a 1:1 square version of the same image, same scene and device").
4. Save the 16:9 versions as PNG into the repo:
   - `public/concepts/hero.png`
   - `public/concepts/cutaway.png`
   - `public/concepts/flow.png`
   - Square variants (for slides only): `hero-square.png`, `cutaway-square.png`, `flow-square.png` in the same folder.
5. The app's How it works tab picks up the three main files automatically. Check that no text, logos or brand names slipped in before using any image.

## Shared style block (paste first)

> I'm going to ask for three images of the same small DIY soil-sensor device for a student pitch. Keep the device identical in all three:
> a small, matte light-grey ABS plastic junction box, about 12 × 8 × 6 cm, with rounded corners, four visible corner screws on the lid, and two black nylon cable glands on the bottom face. One flat grey cable goes to a slim black capacitive soil-moisture probe (a flat circuit-board blade about 10 cm long); one round black cable goes to a short stainless-steel waterproof temperature probe. The box is mounted with two zip ties on a short weathered cedar stake.
> It is a hand-assembled prototype from hobbyist parts, not a commercial product: no branding, no product styling, no display screen, no buttons, no antennas sticking out, no solar panel.
> Style: realistic and grounded, not sci-fi, no glowing parts, no holograms. No text, no letters, no numbers, no logos, no brand names anywhere in the image.

## Follow-up refinement prompts

Use these in the same chat as needed:

- "Make the enclosure smaller, about the size of a deck of cards next to a hand, keep everything else the same."
- "Show the two black cable glands on the bottom of the box more clearly, with the cables entering through them."
- "Remove any text, letters, numbers or logos that appear anywhere, including on chips and the USB adapter."
- "Make it look more like a hand-built prototype and less like a finished commercial product."
- "Make it less futuristic: no glow, no LEDs, no screen on the device."
- "Keep the same enclosure colour and shape as the previous image."
- "Make the background mountains more subtle so the device is the focus."
- "Now make a 1:1 square version of the same image, same scene and device, recomposed so the device stays centred."
- "Lighten the infographic background and increase spacing between the five steps."
